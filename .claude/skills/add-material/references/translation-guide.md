# 字幕翻译规范

把英文 SRT 翻译成简体中文 SRT。读者是正在学英语的人：听的时候看中文理解意思，也会拿中文和英文逐句对照。

## 要求

1. **先通读全文**：翻译前理解整份字幕的话题、人物关系、语气和幽默。
2. **格式不变**：句数、序号、顺序、时间轴和原文完全一致。只输出合法的 SRT，UTF-8 编码，不加 Markdown 代码块和说明。
3. **译意思，不译词序**：用自然的口语中文，原文刻意正式时才用正式的说法。
4. **准确**：人名、术语、数字、单位、否定、不确定语气、程度、逻辑关系都要保留。
5. **结合上下文**：代词和省略的主语根据前后句补全；一句话被拆成几段字幕时，合起来理解，再把中文分回原来的几段。
6. **方便对照**：在自然的前提下，尽量让中文的信息顺序和英文接近，方便学习者把中文和英文对应起来。不要为了顺口把一句话的意思挪到另一句字幕里。
7. **简洁**：要能在字幕显示的时间内读完。只去掉不带语气和意思的口头填充词（um、uh），有实际内容的一律保留。
8. **不添加**：不加解释、背景知识、括号注释、译者注，也不加原文没有的内容。
9. **笑话和双关**：尽量找自然的中文对应；找不到时优先保留意思和语气，不加注释。
10. **前后一致**：反复出现的人名、称呼和术语，全文用同一个译法。人名一般保留英文。

## 自查

写完后逐句对照英文检查：有没有漏译、意思反了、人名数字错了、中文不自然、句子太长、跨句的意思断了。有问题改完再保存。
