设计取向

核心动作只有一个：边听边点。所以播放页把字幕放在最大的区域，控制按钮集中在拇指够得到的底部。点词查释义时音频自动暂停，关掉弹层接着播，听的节奏不会被打断。

页面结构

材料（首页）→播放页→释义弹层
生词本→释义弹层→去原文听

底部只有两个 Tab：材料和生词本。首页顶部的「继续听」直接回到上次停下的那句。

播放页的操作

点荧光标记
弹出释义，音频暂停；关闭后继续播放。短语里任意一个词都能点
点没有标记的词
显示“未收录”，可以听发音。要不要接词典见下方待确认
点句子其他地方
从这句开头开始播
点或拖波形
跳到任意位置。深色是已播，灰色是当前句的范围
上一句 / 下一句
按句跳。句子播到一半时点上一句，先回到本句开头
单句循环
当前句反复播，适合跟读。波形上循环的范围变成黄色
倍速
1.0× → 0.75× → 0.5× → 1.25× 循环切换
手动滚动字幕
暂停自动跟随，出现「回到当前句」
电脑上预览
空格播放或暂停，← → 切换句子

三种字幕模式

  • 双语：英文加中文，第一遍听时用。
  • 英文：隐藏中文，逼自己看英文理解。
  • 盲听：字幕模糊，只听。没听懂的句子点一下再显示。

视觉

荧光笔黄只用来标“可以点的词”，不用在别处，所以一眼就能看出哪里有释义。当前句靠文字深浅区分，不加色块，减少干扰。英文用衬线体 Literata，读起来像书页；中文和界面用系统字体。

模拟材料

3 段原创对话，用 macOS 自带的英文语音逐句合成后拼接，所以 SRT 的时间轴是精确的。48kbps 单声道，85 秒的音频约 0.5MB。每句的标注由脚本自动对齐到具体的词和短语。

落地到小程序

  • 音频用 InnerAudioContext；如果要锁屏继续播，换成 BackgroundAudioManager。
  • 字幕列表用 scroll-view 的 scroll-into-view 跟随当前句。
  • 学习进度和生词本存在本地（wx.setStorageSync）。
  • 材料 JSON 打包在分包里，音频走 GitHub + jsDelivr。

需要你确认

  1. 没有标注的词，点了要不要显示词典释义？需要把一份精简词典打进包里。
  2. 要不要支持锁屏和后台继续播放？
  3. 生词本要不要加「复习」，比如卡片翻面、按原句重听？
  4. 小程序里用 Literata 需要从网络加载字体（约 100KB），也可以直接用系统字体。
