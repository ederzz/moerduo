# 素材格式

这份文档是素材格式的唯一标准。`add-material`、`word-notes` 两个 skill 和 `scripts/material.py` 都以它为准，改格式时一起改。

## 目录结构

每份素材一个文件夹，放在 `materials/` 下，文件夹名就是素材 ID（slug）：小写英文，用连字符连接，一旦确定不要改，因为学习进度和生词本都用它来关联。

```
materials/
  catalog.json    素材目录：登记过的素材才会进小程序
  running-late/
    audio.m4a     音频
    en.srt        英文字幕
    zh.srt        中文字幕
    words.txt     你要查的词和短语，每行一个
    notes.md      释义，由 words.txt 生成
```

## 制作流程

1. 在 `materials/` 下新建一个文件夹，放进音频（mp3、m4a 都行）或视频，再放英文字幕，文件名随意。然后运行 `/add-material`，它会：
   - 整理成标准文件，生成 `audio.m4a`，源文件移到废纸篓；
   - 翻译 `zh.srt`（自带中文字幕且对得上时直接用）；
   - 最后登记到 `catalog.json`。
2. 自己读字幕，把不认识的词和短语写进 `words.txt`。
3. `/word-notes <slug>`：为 `words.txt` 里还没有释义的行生成释义，追加到 `notes.md`。

以后再往 `words.txt` 里加词，重新运行第 3 步即可，已有释义的行会跳过。

以 `_` 或 `.` 开头的文件夹会被脚本忽略，可以用来放草稿。

## catalog.json

素材目录。**只有登记在这里的素材才会进小程序**，由 `add-material` 在最后一步登记，不用手写。

```json
[
  {
    "id": "running-late",
    "title": "Running Late",
    "titleZh": "差点迟到",
    "level": "B1",
    "tags": ["职场", "对话"],
    "addedAt": "2026-09-29T20:02:50+08:00",
    "source": "可不填"
  }
]
```

| 字段 | 说明 |
|---|---|
| id | 素材文件夹名 |
| title / titleZh | 英文标题、简短的中文标题 |
| level | CEFR 等级：A1、A2、B1、B2、C1、C2 |
| tags | 话题标签 |
| addedAt | 处理时间，登记时自动写入，之后更新登记也不变。小程序首页按它排序，新的在前 |
| source | 素材来源，可选 |

- 文件按 `addedAt` 从新到旧排列。
- 不想让某份素材出现在小程序里，从这里删掉它那一项即可，素材文件夹可以留着。
- 查看已登记的素材：`python3 scripts/material.py list`。

## audio.m4a

- AAC 编码，单声道，48kbps。人声完全够用，5 分钟约 1.8MB。
- 由 `add-material` 从你放进去的音频或视频自动转换。源文件建议用 128kbps 左右的 mp3 或 m4a；更高的码率转换后听不出区别。

## en.srt 和 zh.srt

- 标准 SRT，UTF-8 编码。
- `zh.srt` 必须和 `en.srt` **一一对应**：句数、序号、时间轴完全相同，只是文字换成中文。
- 一句字幕在 App 里就是一行可以点的句子，也是「上一句 / 下一句 / 单句循环」的单位。
- 字幕里的 `<i>` 之类的格式标签会被去掉。

## words.txt

读材料时把不认识的词或短语记下来，每行一个，**照字幕里的原文写**，每一行都会生成一条释义。

```
packed
cut it pretty close
@7 heads-up          ← 行首 @数字：只看第 7 句（同一个词在别的句子里意思不同时用）
# 井号开头是注释
```

## notes.md

只放词条，标题等素材信息在 `catalog.json` 里。

### 词条

每个词条以 `## 词条` 开头，紧接着是字段列表，然后是 `### 分节`。

```markdown
## take care of
- 类型: 短语动词
- 本句: 负责处理；搞定

### 近义词
- **handle** 处理，应付
- **deal with** 处理，对付
- **sort out** 搞定，解决
- **look after** 照看，负责

### 近义词比较
- **take care of vs handle**：意思最接近。handle 更强调“有能力处理”，常用于复杂的事：She handles all the client complaints.
- **take care of vs deal with**：deal with 多指处理麻烦、问题，带一点“不得不面对”的意味。
- **take care of vs look after**：look after 偏“照顾”人或东西，take care of 既能照顾人，也能处理事。

### 使用场景
职场和日常都很常用，语气中性。揽下一件事、让对方放心时说：I'll take care of it. 也用于照顾人：Who's taking care of the kids?

### 口语化表达
- **I got it. / I've got this.** 我来，交给我（更随意）
- **Leave it to me.** 交给我吧
- **Consider it done.** 包在我身上（爽快、略带俏皮）

### 例句
- Don't worry, I'll take care of the tickets.
  别担心，票我来搞定。
- Can you take care of my plants while I'm away?
  我不在的时候你能帮我照看一下植物吗？
```

#### 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 类型 | 是 | `单词`、`短语`、`短语动词`、`习语`、`专有名词` 五选一 |
| 本句 | 是 | 在这份材料的这句话里是什么意思。弹层最上面显示的就是它 |
| 匹配 | 否 | 字幕原文和词条写法不一样时用，多个写法用 ` \| ` 分隔，如 `move the deadline up \| Move it up` |
| 句子 | 否 | 只在这些句子里匹配，如 `7` 或 `7, 12` |
| 词性 | 否 | 单词用，如 `adj.`、`v.`、`n.` |
| 音标 | 否 | 单词用，美式音标，如 `/pækt/` |

#### 词条怎么写

- **用词典原形**：字幕里是 `pushes back`，词条写 `push back`，再加 `- 匹配: pushes back`。
- **占位用 sb / sth**：`give sb a hand`，配 `- 匹配: give me a hand`。
- 同一个词条只写一次。它在字幕里出现几次，就会自动关联几处。

#### 分节

App 按「小标题 + 内容」统一显示。内容支持段落、`- ` 列表、`**加粗**`、`*斜体*`。

**每个词条都要有下面 5 个标准分节，按这个顺序写：**

| 分节 | 写什么 |
|---|---|
| 近义词 | 3–5 个意思相近的词或说法，每个后面跟简短的中文意思 |
| 近义词比较 | 词条和主要近义词的区别：语气、正式程度、侧重点、搭配，说清什么时候用哪个，最好配一个短例句 |
| 使用场景 | 谁对谁说、在什么场合说、语气正式还是随意，常见搭配 |
| 口语化表达 | 母语者日常口语里表达同样意思的更随意的说法，或这个词在口语里的常见句式，每个附中文和语气说明 |
| 例句 | 2 个，和原句场景不同，贴近日常 |

确实写不出来时可以省略某一节，校验会给出提醒。

**专有名词**（人名、地名、机构名）不写标准分节，只写字段（类型、音标、本句）和一节 `### 简介`：这是谁或什么地方，和本篇的关系，发音上要注意什么。对人物的描述以素材内容为准，写成「据本篇新闻……」，不补充素材里没有、又无法确认的事实。

可选分节：`英文释义`（放在最前，一句话的英文解释）、`注意`（放在最后，常见错误）。

例句格式：英文一行，中文翻译缩进两格写在下一行。

### 匹配规则

- 不区分大小写，`’` 和 `'` 视为相同，标点不影响匹配。
- **短语会关联到它包含的每个词**：点 take care of 里的任何一个词，都会弹出这条释义。
- **可以跨句**：短语被字幕断成两句时也能匹配上，两句里的对应部分都会被标出来。
- **可以重叠**：`take care of` 和 `care` 都有释义时，点 care 会看到两条，弹层顶部用标签切换，短语排在前面。
- 找不到的词条会被脚本报错，通常是原文写错了，或者需要加「匹配」。

## 校验和构建

**这些命令由 skill 自动运行，不需要你手动执行。** 下面的说明供了解和排查问题用。

校验，有错误时会逐条说明：

```bash
python3 scripts/material.py check running-late
```

查看 `words.txt` 每一行在第几句、是否已有释义：

```bash
python3 scripts/material.py words running-late
```

不写素材名则检查全部。生成小程序数据（输出到 `miniprogram/data/`，两个 skill 做完都会自动构建）：

```bash
python3 scripts/material.py build
```
