# UX 设计

原型（可直接操作）：[prototype/index.html](../prototype/index.html)，在线版 https://claude.ai/artifact/NKiPRjw6n2cNNcRP1MLQsA

本地打开 `prototype/index.html` 即可，`prototype/audio/` 要和它放在一起。原型用的是 v0.1 的数据格式，还没有按 [03-素材格式](03-素材格式.md) 更新。

## 设计取向

核心动作只有一个：**边听边点**。播放页把字幕放在最大的区域，控制按钮集中在拇指够得到的底部。点词查释义时音频自动暂停，关掉弹层接着播，不打断听的节奏。

## 页面结构

```
材料（首页，Tab）──▶ 播放页 ──▶ 释义弹层
生词本（Tab）──▶ 释义弹层 ──▶ 去原文听（播放页）
```

- **首页**：顶部「继续听」卡片，一键回到上次停下的那句。下面是材料列表，每篇显示时长、句数、标注数、难度、进度、是否已存到本地，可以按全部、在学、未开始、已学完筛选。
- **播放页**：字幕列表加底部播放控制。
- **释义弹层**：从底部弹出。
- **生词本**：收藏的词条，按单词和短语分类。

## 播放页的操作

| 操作 | 结果 |
|---|---|
| 点荧光标记 | 弹出释义，音频暂停；关闭后继续播放。短语里任意一个词都能点 |
| 点没有标记的词 | 显示“未收录”（是否接词典待定） |
| 点句子其他地方 | 从这句开头开始播 |
| 点或拖波形 | 跳到任意位置 |
| 上一句 / 下一句 | 按句跳；句子播到一半时点上一句，先回到本句开头 |
| 单句循环 | 当前句反复播，波形上循环的范围变黄 |
| 倍速 | 1.0× → 0.75× → 0.5× → 1.25× 循环 |
| 手动滚动字幕 | 暂停自动跟随，出现「回到当前句」 |

字幕模式有三种：**双语**、**英文**（隐藏中文）、**盲听**（字幕模糊，点一下显示那句）。

## 释义弹层

v0.1 原型的内容顺序：类型、词性 → 词条 → 音标、发音 → 中英文释义 → 原句（可重听）→ 用法 → 例句 → 加入生词本。可以左右切换本篇的上一个、下一个标注。

**v0.2 要改的**（按新的素材格式）：

- 最上面显示「本句」含义，下面是 notes.md 里的自由分节，统一按「小标题 + 内容」显示。
- 一个词被多条释义覆盖时（例如 take care of 和 care），顶部用标签切换，短语排前面。
- 发音按确定的方案实现（见 [01-方案调研](01-方案调研.md#发音方案讨论中)）。

## 视觉

- 荧光笔黄只用来标“可以点的词”，别处不用。
- 当前句靠文字深浅区分（其他句子变淡），不加色块。
- 英文用衬线体 Literata，中文和界面用系统字体。
- 播放页底部的进度条是真实音频的波形。
- 支持深色模式。
