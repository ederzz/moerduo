# 学习状态

App 里的「未开始 / 在学 / 已学完」、进度百分比、「继续听」、生词本、字幕模式等，全部存在**小程序本地存储**里（`wx.setStorage`），不需要服务器，免费。

## 原则

**只存发生过的事，状态靠计算得出。** 例如不存 `status: "在学"`，而是存「最远听到第几句」「什么时候听完的」，显示时再算出状态。这样不会出现存的状态和实际进度对不上的情况。

## 存储的内容

一共 4 个 key，都带版本号，以后格式变了可以做迁移。

### `progress:v1` 学习进度

按素材 ID 存，没听过的素材没有记录。

```json
{
  "running-late": {
    "lastCue": 6,
    "maxCue": 11,
    "cueCount": 20,
    "completedAt": null,
    "updatedAt": 1790671625000
  }
}
```

| 字段 | 含义 |
|---|---|
| `lastCue` | 上次停在哪句（从 0 开始）。「继续听」从这句开头播 |
| `maxCue` | 最远听到哪句，用来算进度 |
| `cueCount` | 记录时这份素材有几句。素材改过、句数变了时用来修正 |
| `completedAt` | 听完的时间，没听完是 `null` |
| `updatedAt` | 最后一次听的时间 |

「继续听」从句子开头播，不从精确的秒数播，这样回来时能听到完整的一句。

### `vocab:v1` 生词本

```json
[
  { "material": "running-late", "note": "heads-up", "addedAt": 1790671625000 }
]
```

只存「哪份素材的哪个词条」，释义内容从素材数据里读。新加的排在前面。

### `settings:v1` 偏好设置

```json
{ "subtitleMode": "bi", "rate": 1, "tipDismissed": true }
```

### `audioCache:v1` 已缓存的音频

```json
{
  "running-late": { "path": "wxfile://usr/running-late.m4a", "version": "v3", "size": 505404, "savedAt": 1790671625000 }
}
```

`version` 是音频地址里的 tag。素材更新后 tag 变了，就重新下载。

## 状态怎么算

| 显示 | 条件 |
|---|---|
| 未开始 | `progress` 里没有这份素材 |
| 在学 | 有记录，`completedAt` 是 `null` |
| 已学完 | `completedAt` 有值 |
| 进度百分比 | `(maxCue + 1) / 句数`，已学完显示 100% |
| 离线可用 | `audioCache` 里有，且 `version` 和当前一致 |

**「继续听」卡片**：在「在学」的素材里取 `updatedAt` 最新的一份；一份都没有就推荐第一份「未开始」的；全部学完就不显示。

**什么时候算「已学完」**：

- 音频播放到结尾（`onEnded`）时，写入 `completedAt`。
- 以后可以在播放页菜单里加一个「标记为学完 / 取消」，手动改。
- 已学完的素材再听，状态保持「已学完」，只更新 `lastCue` 和 `updatedAt`。

## 正在播放的状态

「正在播哪一篇、第几句、是否在播」只存在内存里（`utils/player.js`），不写入本地存储，关掉小程序就没了。首页的卡片和列表、迷你播放条都订阅播放器，实时显示。学习进度照常按下面的时机写入 `progress:v1`。

## 什么时候写入

| 时机 | 写什么 |
|---|---|
| 切换到新的一句 | `lastCue`、`maxCue`、`updatedAt`（最多每 3 秒写一次） |
| 暂停、换素材、关闭迷你播放条、小程序切到后台（`wx.onAppHide`） | 同上，立即写入。离开播放页不再暂停，所以不单独写 |
| 播放结束 | `completedAt` |
| 收藏、取消收藏 | `vocab:v1` |
| 切换字幕模式、倍速 | `settings:v1` |

## 素材更新后的处理

打开素材时，如果句数和 `cueCount` 不一致（字幕改过），把 `lastCue`、`maxCue` 限制在新的句数范围内，再更新 `cueCount`。生词本里的词条如果在新素材里已经删掉，就不显示，也不报错。

## 限制

- 每个小程序每个用户最多 10MB，单个 key 最多 1MB。上面这些数据加起来通常不到 100KB。
- 数据只在这台手机的这个微信里：**换手机、删除小程序会丢失**。小程序版本更新、重新上传体验版不影响。
- 以后需要的话，可以在「我的」页加导出和导入：把这几个 key 转成一段文本，复制到剪贴板备份。
