# 方案调研

记录于 2026-09-29。

## 需求

- 微信小程序。
- 播放自己准备的英语材料，显示字幕；点字幕里的单词或短语，显示对应的释义。
- **不能花钱**：开发、托管、存储都要免费。
- 加载要尽量快。

## 结论

| 部分 | 方案 |
|---|---|
| 小程序 | 个人主体注册（免费），长期用**体验版**，不正式发布 |
| 材料形式 | **音频**代替视频，2–5 分钟一份 |
| 字幕和释义 | 在 GitHub 仓库维护，构建成 JSON **打包进小程序分包** |
| 音频 | GitHub 公开仓库 + jsDelivr CDN 在线播放，听过的缓存到手机本地 |
| 学习进度、生词本 | 小程序本地存储，见 [04-学习状态](04-学习状态.md) |

## 小程序怎么零成本

- 个人主体注册小程序免费；企业认证每年 300 元，不需要。
- 只给自己用时，不正式发布，一直用「体验版」：
  - 不用审核，不用做小程序备案，也不受个人主体可选类目的限制（视频、教育类正式发布可能需要资质）。
  - 可以加少量体验成员。
  - 手机上打开「开发调试」后不检查请求域名白名单。
- 开发工具免费，也不需要服务器。
- 如果以后要公开给别人用，就得正式发布，需要做小程序备案、选类目，届时再评估。

## 存储方案对比

| 方案 | 费用 | 国内速度 | 问题 |
|---|---|---|---|
| GitHub 原始文件地址直连 | 免费 | 很慢，经常打不开 | 不推荐 |
| GitHub + jsDelivr | 免费 | 一般，不太稳定 | 单文件不能超过 20MB；仓库必须公开 |
| 打包进小程序 | 免费 | 最快 | 总包 20MB、单个分包 2MB，适合放文本 |
| 手机本地存储 | 免费 | 最快 | 约 200MB 上限，需要先下载或导入 |
| 七牛、腾讯云等对象存储 | 有免费额度 | 快 | 需要自己的域名并备案，实际无法零成本 |
| 微信云开发 | 已收费 | 快 | 不符合要求 |

## 为什么用音频而不是视频

一开始考虑的是视频加字幕。视频的问题：

- 480p 视频 5 分钟约 30MB，超过 jsDelivr 的 20MB 单文件限制，在国内加载也慢。
- 唯一又快又免费的办法是手动导入到手机，太麻烦。

换成音频后：

| 时长 | 48kbps 单声道音频 | 480p 视频 |
|---|---|---|
| 2 分钟 | 约 0.7MB | 约 12MB |
| 5 分钟 | 约 1.8MB | 约 30MB |

实测：85 秒的模拟对话，音频 0.5MB。

- jsDelivr 加载 1–2MB 只要几秒，音频还是边下边播。
- 据了解，小程序播放网络音频不检查合法域名，需要用真机验证一次。
- 代价是没有画面，另外公开仓库里的音频谁都能下载，有版权风险的素材要注意。

## 音频地址

```
https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@<tag>/materials/<slug>/audio.m4a
```

- 用 tag 或 commit 号，不要用分支名，分支名有缓存延迟。
- 代码里准备几个备用域名，一个加载失败就换下一个：`cdn.jsdelivr.net`、`fastly.jsdelivr.net`、`gcore.jsdelivr.net`。
- 缓存到本地要用 `wx.downloadFile`，它会检查域名白名单；体验版打开调试模式可以跳过。

## 新增材料的流程

1. 用 `add-material` skill 新建素材：放入英文字幕、提取音频、翻译中文字幕。
2. 把不认识的词写进 `words.txt`，用 `word-notes` skill 生成释义。
3. 运行 `python3 scripts/material.py check` 校验。
4. 提交、打 tag、推送到 GitHub。
5. 在开发者工具里重新上传体验版（字幕和释义打包在小程序里）。

## 发音方案（讨论中）

| 方案 | 说明 | 稳定性 |
|---|---|---|
| 重听原句 | 用材料自己的音频，语境里听最自然。原型已实现 | 最稳 |
| 预先合成词条读音 | 构建时给每个词条生成约 10KB 的音频，随材料放 GitHub。可用 macOS 系统语音或 edge-tts（非官方接口） | 稳 |
| 有道发音链接 | `dict.youdao.com/dictvoice?audio=单词`，零工作量 | 非官方，可能失效 |
| 微信同声传译插件 | 官方免费插件，有调用额度，需要实测 | 待验证 |

建议：重听原句 + 预先合成读音。
