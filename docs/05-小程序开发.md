# 小程序开发

原生小程序（WXML / WXSS / JS），不用框架，不用 npm，用微信开发者工具直接打开。

## 目录

```
project.config.json        开发者工具的项目配置（appid 在这里）
miniprogram/
  app.js / app.json / app.wxss / theme.json
  config.js                音频地址配置
  data/                    素材数据，由 scripts/material.py build 生成，不要手改
  pages/home/              材料列表（Tab）
  pages/vocab/             生词本（Tab）
  pages/player/            播放页
  components/note-sheet/   释义弹层，播放页和生词本共用
  custom-tab-bar/          底部 Tab 栏
  utils/                   本地存储、进度、生词本、音频地址、释义数据
  styles/icons.wxss        图标，由 scripts/gen_icons.py 生成
```

## 在开发者工具里运行

1. 打开微信开发者工具 →「导入项目」→ 选择仓库根目录 `moerduo/`。AppID 先用「测试号」即可。
2. 在仓库根目录启动本地服务器，模拟器里就能播放 `materials/` 下的音频：

   ```bash
   python3 -m http.server 8765
   ```

   本地服务器只在开发者工具里使用（`config.js` 的 `devBase`），真机上会自动跳过。
3. `project.config.json` 里已经关闭了合法域名校验，开发时不用配置域名。

## 素材数据怎么进小程序

字幕和释义打包在小程序里，音频走网络：

- `add-material`、`word-notes` 两个 skill 做完会自动运行 `material.py build`，更新 `miniprogram/data/`。
- 只有登记在 `materials/catalog.json` 里的素材才会被构建。首页的顺序就是登记的处理时间，新的在前。
- 构建时会把 Markdown 分节预先解析好，并从音频生成波形，小程序里不再做这些处理。
- `data/index.js` 用静态的 `require` 引入每份素材。如果写成动态路径，上传时这些文件会被当成无用文件过滤掉。
- 主包上限 2MB，一份素材的数据大约 20–40KB，目前可以放几十份。素材多了以后，要把播放页和数据拆到分包里。

## 真机播放：音频放到 GitHub

1. 在 GitHub 新建一个**公开**仓库（例如 `moerduo`），把这个仓库推上去。
2. 打一个 tag 并推送：

   ```bash
   git tag v1
   git push origin v1
   ```

3. 修改 `miniprogram/config.js`：`github.repo` 粘贴仓库链接（如 `https://github.com/yourname/moerduo`），`ref` 填刚才的 tag。
4. 之后新增或更新音频：提交、打新 tag（v2、v3……）、推送，再改 `ref`，重新上传体验版。

音频地址按顺序尝试：本地缓存 → `cdn.jsdelivr.net` → `fastly.jsdelivr.net` → `gcore.jsdelivr.net`。

## 离线缓存

音频第一次在线播放成功后，会在后台下载到手机本地（`wx.downloadFile`），首页显示「离线可用」。

`downloadFile` 需要合法域名：

- 在小程序后台「开发管理 → 开发设置 → 服务器域名」里，把上面三个 jsDelivr 域名加到 downloadFile 合法域名。
- 如果加不上，体验版在手机上打开「开发调试」也能用。
- 缓存失败不影响在线播放。

## 发布体验版

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 用个人身份注册小程序（免费），拿到 AppID。
2. 把 `project.config.json` 里的 `appid` 从 `touristappid` 改成你的 AppID。
3. 开发者工具里点「上传」，然后在小程序后台「版本管理」把这个版本设为体验版。
4. 在「成员管理」里添加体验成员。
5. 用微信扫体验版二维码打开。

不提交审核，不正式发布。

## 修改图标

图标定义在 `scripts/gen_icons.py`，改完后运行：

```bash
python3 scripts/gen_icons.py
```

WXSS 不能引用本地图片，所以图标是 base64 的 SVG 蒙版。颜色跟随文字颜色，深色模式自动适配。用法是 `<text class="i i-play"></text>`，组件里要自己 `@import "/styles/icons.wxss"`。

## 与原型的差异

- 字幕文件里没有说话人信息，所以不显示说话人，只显示时间。
- 英文用系统衬线字体（iOS 是 Georgia），没有加载 Literata。
- 暂时没有单词发音按钮，只有「重听这句」。
- 已实现重叠释义的标签切换：弹层顶部显示多个词条，短语排在前面。
